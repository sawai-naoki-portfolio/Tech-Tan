# 要件定義書 — テク単

## 1. 背景と課題

情報処理技術者試験（ITパスポート・基本情報技術者・応用情報技術者）の学習では、

- **用語の暗記**と**過去問演習**で別々のアプリやサイトを行き来する
- 下位試験で覚えた用語が上位試験の前提になるのに、学習範囲がつながっていない
- IPA の問題文は JIS 表記（センサ・サーバ）で、学習者が入力する長音付きの表記（センサー・サーバー）では検索に引っかからない

といった不便がありました。

## 2. 目的

**IT 用語の単語帳と過去問演習を 1 つにまとめ、IP → FE → AP と積み上げて学べるアプリ**を提供する。資格学習アプリ「簿記単」の続編として、設計思想と UI/UX を引き継ぎつつ、出題まわりを情報処理技術者試験向けに作り直す。

## 3. 対象ユーザー

| ペルソナ | 特徴 |
|---|---|
| IT パスポートを受ける学生・社会人 | IT の基礎用語から覚えたい。スキマ時間にスマホで学習 |
| 基本情報・応用情報の受験者 | 過去問を年度別・分野別に繰り返し解きたい。苦手を集中的に潰したい |

## 4. 機能要件

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | 試験の切り替え | IP / FE / AP。実践問題・単語テスト・ニュースの既定範囲がまとめて切り替わる |
| F-02 | 単語検索 | 用語名・読みガナから検索。表記ゆれ（長音・カタカナ/ひらがな・全角/半角・区切り記号・エー/エイ）を吸収 |
| F-03 | 単語一覧 | 選択中の試験までの累積で表示（IP 673 → FE 1,456 → AP 2,176 語） |
| F-04 | マイリスト・保存 | 単語をグループ化して保存。ドラッグ＆ドロップで並び替え |
| F-05 | メモ・カスタム単語 | 単語ごとのメモ、収録外の単語の追加 |
| F-06 | 単語カードの共有 | 単語カードを画像として SNS に共有 |
| F-07 | 単語テスト | 説明文から用語を当てる 4 択。範囲は試験ごとに選択 |
| F-08 | 単語チェック問題 | 登録した単語だけで出題。誤答の選択肢は全単語から集める |
| F-09 | 実践問題（過去問） | 午前問題 9,820 問。ランダム／年度別／苦手復習 |
| F-10 | 出題範囲の絞り込み | 大分類・中分類 × 実施回（全期間／直近 5 回／個別） × 問題数。試験ごとに保存 |
| F-11 | 図表の拡大 | タップで全画面ピンチズーム。選択肢が画像の問題にも対応 |
| F-12 | 解説と出題回 | 解答直後に正誤・解説・同一問題の出題回を表示 |
| F-13 | 電卓 | 演習中いつでも呼び出せる（稼働率・基数変換など） |
| F-14 | 結果と合格ライン | 正答率と合格ライン 60% の達成状況 |
| F-15 | 過去問一覧 | 全問／あとで解き直す／間違えた問題。本文検索・分野・回で絞り込み |
| F-16 | ミス回数記録 | 単語・過去問それぞれで誤答回数を記録し、苦手復習に反映 |
| F-17 | 学習スケジュール | カレンダーで予定とタスクを管理。受験日（最大 3 件）までの残り日数 |
| F-18 | IT ニュース | 試験別タブで Google ニュースを表示 |
| F-19 | 設定 | テーマ・Material 3・項目別キャッシュクリア・検索履歴・メモ一覧 |

## 5. 非機能要件

| 区分 | 要件 | 実現方法 |
|---|---|---|
| 可用性 | オフラインで学習できる | 単語・過去問・図表をすべて同梱 |
| 性能 | 起動を遅くしない | 過去問は開いた試験だけを読み、パースは別 isolate |
| 性能 | 入力中にカクつかない | 検索は 250ms デバウンス、結果リストだけを再描画 |
| 使いやすさ | 小さい図表を読める | 全画面ピンチズーム |
| 使いやすさ | 画面サイズに追従する | `ResponsiveSizes` で余白・文字サイズを調整 |
| 保守性 | データ不整合を早期に検出する | 問題 ID の一意性・正解記号・画像の実在・`pubspec.yaml` への登録をテストで検証 |
| 保守性 | 出題ロジックを端末なしで検証できる | `ExamQuizFilter.apply` などを純粋ロジックとして単体テスト |
| 権利 | 第三者の著作物を配布しない | 解説を自前の文章へ差し替え、写しになっていないかをツールで検証 |
| 容量 | ストア配信サイズを抑える | App Bundle / `--split-per-abi` |

## 6. 簿記単からの変更点

| | 簿記単 | テク単 |
|---|---|---|
| 対象資格 | 簿記（3 級〜1 級）1 種類 | IP / FE / AP の 3 種類を切り替え |
| 実践問題 | 仕訳問題（記述式） | 過去問の 4 択。図表・選択肢画像あり |
| 出題範囲 | 級 × 商業/工業 の 3 通り | 出題方式 3 種 × 分野（3 系＋中分類）× 実施回 |
| 出題順 | ランダムのみ | ランダム / 年度別（本番と同じ順） / 苦手復習 |
| 補助ツール | 金額入力用の電卓 | 計算問題用の電卓 |
| 成績表示 | 正解数 | 正解数＋正答率＋合格ライン(60%) |
| 単語の範囲 | 範囲の概念なし | 試験の包含関係にもとづく累積 |
