# テスト仕様・結果 — テク単

## 1. 方針

| 種類 | ねらい |
|---|---|
| **同梱データの整合性テスト** | 9,820 問・2,176 語・約 3,100 枚の画像は手で確認しきれない。壊れたデータは「実機でだけ図が出ない」など気付きにくい不具合になるため、テストで機械的に検証する |
| 純粋ロジックの単体テスト | 出題条件・表記ゆれ正規化・試験の包含関係・和暦の解釈を、端末なしで仕様として固定する |
| 解説の差し替えの検証 | 自前で書いた解説の長さ・正解への言及・同一問題間の整合性を確認する |

## 2. 実行方法

```bash
flutter pub get
flutter test
```

## 4. 既知の課題

| 課題 | 状況 |
|---|---|
| 元データの図表画像が 2 件欠けている | アプリは代替表示に倒れる。一覧はテスト内の `_knownMissingImages` |
| 同一問題の解説が回によって食い違うもの（元データに 323 件） | 解説の自前化（同一問題すべてに反映）で解消予定 |
| 解説の自前化は 100 / 9,820 問 | ITパスポート 令和 8 年春期は全問完了。ポートフォリオ公開版には差し替え済みの解説だけを同梱 |
| アプリアイコン・スプラッシュ画像が未配置 | リリース前に対応 |
